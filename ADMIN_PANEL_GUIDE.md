## 📋 FEATURE GUIDE

### 2. **PRODUCTS TAB** (Inventory Management)
Manage your product catalog with full CRUD operations.

#### 📱 Search Products
- Use the search bar to filter products by name
- Results update in real-time as you type

#### ➕ Create New Product
1. Click **"New piece"** button
2. Fill in the form:
   - **Name** (required): Product name
   - **Category** (required): Type of product
   - **Price USD** (required): Price in US dollars
   - **Image Path** (required): e.g., `/images/jacket.jpg`
   - **Sizes** (optional): Comma-separated, e.g., `S, M, L, XL`
   - **Colors** (optional): Comma-separated, e.g., `Black, Navy, White`
   - **Detail** (optional): Product description
3. Click **Save** to create
4. Product appears immediately in inventory

#### ✏️ Edit Product (Including Price)
1. Click the **Edit** button (green) next to product
2. Form pre-fills with current product data
3. Modify any field:
   - **Price**: Change the USD price
   - **Details**: Update description, sizes, colors
   - **Image**: Change product image path
4. Click **Save** to update
5. Changes reflect immediately across the system

#### 🗑️ Delete Product
1. Click the **Delete** button (red) next to product
2. Confirm in the dialog
3. Product removed from inventory

**Pro Tip:** Prices can be updated anytime without affecting existing orders.

---

### 3. **ORDERS TAB** (Order Pipeline)
Manage customer orders and track fulfillment status.

#### 🔍 Search Orders
- Search by customer email to find specific orders
- Shows all orders matching the email

#### 📦 Order Details
Each order displays:
- **Customer Email:** Buyer contact
- **Date Created:** When order was placed
- **Items:** Product names with quantities and variants (size/color)
- **Total Amount:** Order value in USD
- **Status:** Current fulfillment state

#### 📊 Order Status Workflow
Change order status using the dropdown. Valid statuses in order:
1. **pending** - New order, awaiting payment
2. **paid** - Payment received via Paystack
3. **processing** - Order being prepared for shipment
4. **shipped** - Order sent to customer
5. **completed** - Order delivered
6. **cancelled** - Order cancelled

**Example Workflow:**
```
pending (new order)
  ↓
paid (customer paid via Paystack)
  ↓
processing (packing the order)
  ↓
shipped (sent to delivery)
  ↓
completed (delivered to customer)
```

**Actions:**
- Click the status dropdown
- Select new status
- Status updates instantly
- Dashboard revenue metrics refresh automatically

---

### 4. **REVENUE TAB** (Analytics Dashboard)
View business performance and financial metrics.

#### 📈 Key Metrics
- **Total Revenue:** Sum of all paid orders (USD)
- **Completed Orders:** Count of orders with "completed" status
- **Average Order Value:** Total revenue ÷ number of paid orders
- **Pending Revenue:** Expected revenue from orders not yet shipped

#### 📊 Status Breakdown Table
Detailed breakdown showing for each order status:
- Count of orders in that status
- Total revenue generated by orders in that status

**Use Cases:**
- Track business growth
- Identify bottlenecks (lots of pending/processing?)
- Calculate average customer order value
- Forecast cash flow from pending revenue

### 5. **CAC TAB** (Business Verification)
Verify your business details using Corporate Affairs Commission (CAC).

#### 🏢 CAC Verification
1. Enter your **CAC Registration Number**
2. Click **Verify**
3. System validates against CAC database
4. Response shows:
   - ✅ **Success** (green): Business verified
   - ❌ **Error** (red): Invalid registration or API issue

**Note:** Requires CAC_API_KEY configuration in .env file.

## 🛡️ Security Best Practices

1. **Login Security**
   - Keep your password private
   - Log out when finished
   - Don't share admin URL with customers

2. **Price Management**
   - Double-check prices before saving
   - Prices only affect new orders (doesn't change past orders)
   - Keep historical pricing if needed

3. **Order Management**
   - Mark orders as "shipped" only when actually sent
   - Use "cancelled" status for orders that won't be fulfilled
   - Keep order records for refunds/disputes

4. **Admin Accounts**
   - Create separate accounts for each team member
   - Don't share credentials
   - Remove access immediately when team member leaves

## 📞 Support

If you encounter any issues:

1. **Login fails:** Check email/password are correct
2. **Products not appearing:** Refresh page (Ctrl+R)
3. **API errors:** Check server is running on port 5000
4. **Images not showing:** Verify image path is correct in product form
5. **Status not updating:** Make sure you have internet connection

## 🎓 Tips & Tricks

### Inventory Management
- Use descriptive product names for easy searching
- Include size/color details in the detail field if products have multiple variants
- Update product images regularly for better visual appeal
- Keep prices consistent with your front-end store

### Order Fulfillment
- Check **ORDERS** tab daily for new orders
- Move orders through pipeline: pending → paid → processing → shipped → completed
- Use search to find orders by customer email quickly
- Monitor **pending revenue** to see cash flow forecast

### Analytics
- Check **REVENUE** tab weekly to track business growth
- High pending orders? Maybe expedite processing
- Low average order value? Consider upselling strategies
- Use revenue breakdown to understand which status products are stuck in

### Admin Management
- Create admin accounts for key team members
- Use real names for easier identification
- Periodically audit who has admin access
- Update admin passwords every 90 days
